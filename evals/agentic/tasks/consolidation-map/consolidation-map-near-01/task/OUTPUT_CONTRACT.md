# Deliverable interface

Write `consolidation-map.md` in the same layout as a finished map: counts line, one `## Unit:` section per decided unit (rows, `Why:`, `What's lost:`), a closing `## Unchanged` section and a `## Reconciliation` section. Record only the decisions supplied. An entity with no supplied decision is named `UNDECIDED`, gets no verb row, and is listed in the Reconciliation section under `RECONCILIATION FAILED`.
