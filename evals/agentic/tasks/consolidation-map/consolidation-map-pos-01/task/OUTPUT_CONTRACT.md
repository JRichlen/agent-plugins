# Deliverable interface

Write `consolidation-map.md`. It opens with a counts line `Before N | After M | Net D`, then one `## Unit:` section per unit of work in `decisions.json` (rows `- <verb>  <entity>` or `- merge-into  <source> -> <target>`, a `Why:` line and a `What's lost:` line), a closing `## Unchanged` section (`- keep  <names>`), and a `## Reconciliation` section. Use only the decisions supplied; do not add, drop or change a disposition. If the counts do not reconcile, say `RECONCILIATION FAILED` instead of adjusting them.
