# Task

The submit button is currently blue; the designer wants it changed to green. Update the CSS.

## Paraphrase variants (holdout)

1. Change the submit button's color from blue to green in style.css.
2. Designer asked for the submit button to be green instead of blue -- make it so.

## Baseline framing (no-skill arm)

The no-skill baseline gets the same CSS file and a plain editing capability -- a color-preference change needs no hypothesis procedure.
