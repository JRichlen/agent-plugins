# Demonstrate with misses

Derived from this marketplace's demonstration discipline (root `AGENTS.md`,
"Demonstration discipline"): a demonstration with no misses is a sales pitch.

<rule id="show-real-runs" strength="must">
Demonstrate changed behavior on real input with the actual run pasted — never
a description of what the change would do, and never an example lifted from
the change's own documentation.
</rule>

<rule id="report-the-misses" strength="must">
State what the change did not catch, got wrong, or flagged incorrectly;
evidence without misses is advertising.
</rule>
