# Retired coordination product

This directory is a migration notice, not an installable plugin or a live skill.
Use [delegated execution](../delegated-intelligence/README.md) for bounded worker
assignments. Shared rules and task state come from the operating core.

The former coordinator persona, duplicated boards, model tiers and observer
policy were removed rather than copied under a new name. See the
[caller migration guidance](../../README.md#current-status-and-migration) for invocation and
activation changes. Installed copies and global instruction fragments are not
modified by this repository change.
