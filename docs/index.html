Documentation site for JRichlen/agent-plugins — a Claude Code plugin marketplace whose plugins also work with any coding agent (Codex, Cursor, Gemini, …) via standard SKILL.md + AGENTS.md entry points.

/plugin marketplace add JRichlen/agent-plugins
/plugin install <name>@jrichlen

Plugin deep dives

protocol

redgate

Run any idea through rounds of ARM → TRACE → JUDGE with graduated autonomy: a verifier is proven able to fail before any work starts, one thin slice flips one criterion green, and someone who did not do the work runs the verifier. Gates classified PATCH/MINOR/MAJOR, so derived work flows inside a human-approved mandate while irreversible decisions always block on the human.

documentation →
compiler

agent-compiler

Compile deterministic, content-hashed agents from small behavior modules instead of hand-writing persona prompts: fuzzy intent becomes a typed AgentQuery, then a stdlib-only kernel resolves modules, fails closed on conflicts and over-ceiling effects, and emits an immutable AgentImage with per-line provenance.
