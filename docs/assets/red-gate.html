The gate opens only when everything fails

This is the counterintuitive core, so try it. Every checkable criterion must execute and come back FAIL before any work is allowed to start. Click a verdict to flip it and watch the gate.

.redgate/add-retry/check.sh

A criterion that is already green proves nothing — it was true before you started. An UNVERIFIABLE criterion needs a human countersignature at BEGIN, and never counts toward the gate.

Red gate
BLOCKED
Not red means harness failure only — no verdict line, reserved exit 99, or a dirty preflight, which covers only the harness's own prerequisites and never the binaries under test. A check_cmd exiting non-zero, 127 included, is a legitimate FAIL.
02

One shape, all the way down

Every node runs the same three stages — the root triggered by /redgate "<idea>", and every child spawned beneath it. Each stage has a hard exit condition; nothing advances without it.

Begin

Write a contract, then prove it can fail.

  • At most 5 interview questions, one at a time, each with a default that silence accepts.
  • Emit CRITERIA.md (3–7 numbered criteria) and check.sh.
  • Each criterion records why it is red, plus a positive control: the same check shape against a known-good target, passing today.
  • Human ratifies once — shown the actual red output, not seven bash -c lines.
  • sha256 of both files pinned into the manifest.

EXIT gate red + ratified
two files exist · every checkable criterion FAIL · harness preflight clean

Middle

One writer, one vertical slice.

  • Take the frontier criterion crossing the most layers.
  • Cut one slice that flips exactly that id FAIL→PASS through every layer it names — no stub at the seam the slice exists to prove.
  • Subagents fan out read-only: search, analysis, options. They never edit.
  • Every hunk traces to a criterion id, or is tagged enabling: / counted in a capped incidental bucket.
  • .redgate/** is deny-listed. The writer cannot touch the contract or the checker.

EXIT check.sh re-run
bound scaled to layer count · first exhaustion is a re-plan, not a failure

End

Someone who didn't write it runs the script.

  • A fresh subagent gets only the criteria, the script, and the diff — never the transcript.
  • Re-hash both files. Either mismatch fails the run outright as drift.
  • PASS requires evidence on disk, written by check.sh, newer than the run start.
  • Mutation control: revert the core hunk, re-run. Still passing means it was never coupled — that is UNVERIFIABLE, not green.
  • Verdict, per-criterion table, unmet ids, one next-smallest-slice suggestion.

EXIT accept / again / split
split needs a named seam and child criteria already proven red

06

What the marketplace still lacks

Red Gate is a protocol, not an implementation. Ten skills would have to exist for it to run — three of them before it can run at all.

Grounded in surveyed patterns rather than invented: orchestrator-worker and the task-description contract (Anthropic), the workflow taxonomy from Building Effective Agents, plan-and-execute (LangChain), ReAct (Yao et al.), Reflexion (Shinn et al.), HTN decomposition, blackboard architecture, contract-net, ADaPT's as-needed decomposition, and Huang et al. (ICLR 2024) on why a model cannot check its own work. Full spec: docs/red-gate-protocol.md.
