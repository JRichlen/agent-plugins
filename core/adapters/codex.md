# Codex adapter

Repository-only integration notes; no global file or setting is changed.

The root `AGENTS.md` points to the [operating contract](../OPERATING.md). Respect
the host's directory-scoped instruction rules when working in another tree.
A separate persistent adoption requires an explicit reviewed instruction change;
do not copy evolving policy into multiple global fragments.
See the [portable adapter](portable.md) for generated selected-method core copies;
those copies are distinct from approved always-on host adoption.

Use the runtime's actual skill and command identifiers. Workers require a real
delegation tool; sequential passes do not provide an independent reviewer.
Use a native structured choice tool only when it is available in the active
mode, otherwise use the contract's compact text fallback. A planned tool call,
assigned worker or pending terminal process is not a completed action.

Record actual tool/host limitations, including filesystem paths, Bash dependencies
and evidence hashing. Do not alter tests or refresh frozen evidence to conceal a
host mismatch. This adapter grants no sandbox, spending or network exception.
