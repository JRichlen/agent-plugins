# GitHub Copilot adapter

Repository-only integration notes; no global file or setting is changed.

Keep the [operating contract](../OPERATING.md) as the policy source. If the chosen
Copilot surface uses generated instructions, its reviewed projection must include
that source and retain provenance; do not create another independently edited
policy copy. Follow the supported host/APM integration rather than assuming that
a `SKILL.md`, hook or root `AGENTS.md` is automatically active everywhere.
See the [portable adapter](portable.md) for generated selected-method core copies;
those copies are distinct from approved always-on host adoption.

Resolve the selected procedure from the installed or repository skill catalog.
Check the surface's real tool, worker and question capabilities. Without a required
independent party, return the verification limitation rather than simulating one.
Permission controls and the existing user mandate still constrain every effect.
The adapter does not provision credentials, enable workflows or select providers.
