# Claude Code adapter

Repository-only integration notes; no global file or setting is changed.

For this repository, the root `CLAUDE.md`/`AGENTS.md` entry point must lead to
the [operating contract](../OPERATING.md). A separate user or project adoption
must explicitly include that canonical contract in the applicable instructions;
installing a plugin is not proof that its repository-root instructions loaded.
See the [portable adapter](portable.md) for generated selected-method core copies;
those copies are distinct from approved always-on host adoption.

Select installed methods through Claude Code's command menu and discoverable
skill descriptions. Plugin commands use the host's namespace; deprecated names
are migration references rather than active routing choices.

Check real worker, permission and independent-review capabilities before using
a service. Hook enforcement applies only when the relevant hooks are actually
loaded. Prefer the native structured question tool when present. Host permission
controls remain authoritative; this adapter does not grant effects, choose a
provider or start recurring work. Preserve the configured model and tool limits.
